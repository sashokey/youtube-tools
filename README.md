Adds native-style recommendation feedback, watched-video filtering, audio-only playback, and manual playlist navigation on desktop and mobile YouTube. Requires [Violentmonkey](https://violentmonkey.github.io/).

## Installation

Open the published `youtube-tools.user.js` in Violentmonkey, confirm installation, and reload YouTube.

## Usage notes

- Hover over or focus a thumbnail on desktop. Tap a thumbnail control on mobile. The actions and **Undo** come from YouTube's card menu.
- **Watched videos** and **Audio only** are available in the account menu on desktop and **Settings** on mobile. Both start off. Changes to audio mode apply when the next video loads or after a reload.
- Playlist playback stops at the end of each video. Use YouTube's **Next**, **Previous**, or playlist items to continue.
- Labels follow YouTube's language and use English when a translation is unavailable.
